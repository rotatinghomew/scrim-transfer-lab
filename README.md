# 不同阵容下的训练迁移与陪练改约

训练表是各周教练收到的裁判片段；`block` 是同一次原定对局，重开及换边片段保留同一值。`opportunities` 指角色实际碰到的已标记指挥情境，`successes` 指成功执行次数。仅 `counted` 片段有可信结果；`restart` 片段不提供该局成绩。替换名单更正按 `known_week` 进入，原行是当时所知。对手档来自当周名单。训练目的以阵容、角色任务、版次、对手档条件定义；改约对方 `released` 回执才表示原档撤销。两个连续 `share` 约定可使用同一档，但不同阵容不得共享。

## 数据包

`sample/` 是本地合成的业务记录，均为 UTF-8 CSV；`table-format.json` 给出各表的列顺序与标量类型，`str` 中 `-` 表示不适用，逗号分隔多值。不同表中同名业务标识用于关联，具体含义见上文。资料入口只检查表头和格式，不对业务状态作判断。

## 运行

使用 Python 3.11 标准库，不需要安装三方依赖。读取样例与运行资料检查：

```sh
python3 intake.py
python3 -m unittest discover -s tests -v
```

也可以将同格式的资料目录作为 `intake.py` 的位置参数。
